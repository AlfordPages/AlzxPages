## 🌟 Tentang Proyek

Website ini merupakan portfolio pribadi yang dirancang untuk menampilkan profil, minat, keterampilan, serta media kontak dalam tampilan yang modern dan futuristik.

Selain berfungsi sebagai portfolio, website ini juga memiliki fitur **Menfess (Anonymous Message)** yang memungkinkan pengunjung mengirim pesan secara real-time menggunakan Firebase.

## 🔥 Firebase Setup

Buat project baru di Firebase lalu aktifkan:

### Authentication
- Google Provider

### Firestore Database
- Start in Production/Test Mode

Kemudian masukkan konfigurasi Firebase pada file:

```javascript
const firebaseConfig = {
  apiKey: "...",
  authDomain: "...",
  projectId: "...",
  storageBucket: "...",
  messagingSenderId: "...",
  appId: "..."
};
```
